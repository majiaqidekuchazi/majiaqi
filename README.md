# 五子棋 · Web 人机对战

一个纯前端、单文件的网页版五子棋：支持 9×9 / 11×11 / 13×13 / 15×15，可与启发式 AI 对战。

## 功能
- 调整棋盘大小
- 黑先人类 vs 白 AI
- 简单/普通/困难难度（启发式评估）
- 无后端、无构建工具，双击 HTML 即可运行

## 本地运行
1. 下载 `index.html`
2. 用浏览器打开它
3. 选择棋盘大小和难度开始对战

## 在线预览
部署到 GitHub Pages / Netlify Drop 后，把链接放在这里。

## 技术栈
HTML + CSS + JavaScript，单文件实现。

## AI 说明
AI 使用进攻/防守启发式评分与简单选择策略，不是最强五子棋引擎；大棋盘时实力会下降。后续可加入 alpha-beta 搜索提升水平。
